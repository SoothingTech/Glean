### 2.2 后端分包职责

包根：`server\src\main\java\com\soothingtech\glean\`

| 包 | 职责 | 关键约束 |
| --- | --- | --- |
| `common\` | 错误码、统一响应包封、业务异常、全局异常处理、时间归一化 | 不依赖任何业务包 |
| `account\api\` | REST 接口层（4 个 Controller）与请求/响应 DTO | 只做参数校验与调用，不写业务 |
| `account\app\` | 业务服务层（认证、授权、设备、审计、幂等、验证码） | 事务边界在此层 |
| `account\domain\` | 实体、仓储接口、授权级别枚举 | 表结构与 Flyway 迁移一一对应 |
| `account\token\` | JWT 签发/解析、认证过滤器、令牌撤销 | 与 HTTP 层解耦 |
| `account\facade\` | 对内接口 `ConsentFacade`、`TokenFacade` 及实现 | 供 ingest/task/remind/view 调用 |
| `account\event\` | `ConsentChanged` 事件发布（Redis Stream） | 只发布，不反向调用业务模块 |
| `account\sms\` | 短信通道抽象与 Dev 实现 | 换真实通道只替换实现 |
| `account\config\` | Spring Security 无状态配置 | 白名单仅认证类接口与健康检查 |

### 2.4 数据库表结构

**V1__account.sql**

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `app_user` | `id` uuid PK、`phone` varchar(20) UNIQUE、`lvl` smallint、`created_at`/`updated_at` timestamptz | 用户账号 |

> 表名使用 `app_user` 而非 `user`：`user` 是 PostgreSQL 保留字，查询时需强制加引号，容易在后续模块埋坑。

**V2__account_consent.sql**

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `consent` | `user_id` uuid PK/FK、`level` varchar(2)（CHECK L0–L4）、`scope` jsonb、`granted_at`、`revoked_at`、`updated_at` | 授权级别与范围 |
| `device` | `id` varchar(64) PK（客户端 deviceId，与 JWT `dev` claim 同值）、`user_id`、`platform`、`last_seen_at`、`revoked_at` | 设备列表 |
| `audit_log` | `id` uuid PK、`user_id`、`action` varchar(48)、`payload` jsonb、`created_at` | 审计记录，索引按 `(user_id, created_at DESC, id DESC)` 与游标分页对齐 |

### 2.6 接口清单

| 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- |
| POST | `/api/v1/auth/sms-code` | 下发验证码（开发环境固定 123456） | 公开 |

| GET | `/api/v1/audit` | 本人审计记录（游标分页） | 需令牌 |
